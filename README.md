# Somsubhra Mukhopadhyay | Portfolio

A single-file portfolio site: `index.html` contains all the HTML, CSS, JavaScript and the profile photo, so nothing else needs to travel with it.

## Publish on GitHub Pages
1. Create a new public repository (for a root URL, name it `<your-username>.github.io`).
2. Upload `index.html` and `README.md` to the repository root.
3. Go to **Settings > Pages**, set Source to **Deploy from a branch**, branch `main`, folder `/ (root)`.
4. After a minute the site is live at `https://<your-username>.github.io/`.

## Preview locally
Extract the zip, then double-click `index.html`.
